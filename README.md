# prova

Browser game pixellato in stile medievale.

## Come giocare

Apri `/home/runner/work/prova/prova/index.html` in un browser.

- **Frecce**: muovi il soldato e salta tra le piattaforme.
- **Click sinistro**: attacco con la spada davanti al personaggio.
- **Click destro (tenuto premuto)**: alza lo scudo e blocca i danni provenienti da davanti.

Obiettivo: fai parkour, sconfiggi i briganti medievali e raggiungi la bandiera a destra per completare il livello.
